## 🏗️ Portfolio Architecture

The portfolio itself is a full-stack TypeScript application — not a static template.

### Technology stack

| Layer | Technology |
| :-- | :-- |
| **Frontend framework** | React 19 + TanStack Start (SSR, file-based routing) |
| **Router** | @tanstack/react-router (typed, file-based) |
| **Language** | TypeScript 5.8 (strict) |
| **Build tool** | Vite 8 |
| **Styling** | Tailwind CSS v4 (CSS-first `@theme` tokens) |
| **UI library** | shadcn/ui (new-york) on Radix UI primitives |
| **Icons** | lucide-react |
| **Data / state** | TanStack Query 5 |
| **Forms & validation** | react-hook-form + zod |
| **Backend** | Supabase — Postgres, Auth, Storage, RLS |
| **Notifications** | sonner |
| **Deployment** | Lovable (edge/Cloudflare Workers target) |

### Design system

| Token | Value |
| :-- | :-- |
| `--primary` | `oklch(0.38 0.14 258)` — deep blue |
| `--primary-soft` | `oklch(0.94 0.04 258)` |
| `--background` | `oklch(0.99 0.003 250)` — near-white |
| `--foreground` | `oklch(0.18 0.03 250)` — slate ink |
| `--radius` | `0.75rem` |
| Font | **Inter** (`--font-sans`) |
| Shadows | `--shadow-soft` · `--shadow-card` · `--shadow-elevated` |

### Key reusable components & hooks

| Item | Purpose |
| :-- | :-- |
| `Layout.tsx` | Sticky navbar with active-page highlighting, mobile hamburger menu, footer with tel/mailto/LinkedIn/GitHub |
| `AdminButton.tsx` | Conditional admin entry point |
| `ui/*` | Button, Card, Dialog, Input, Select, Tabs, Sheet, Toast, and 30+ more Radix-backed primitives |
| `use-auth.ts` | Supabase session subscription + admin authorization |
| `use-mobile.tsx` | Viewport breakpoint detection for the mobile menu |
| `lib/utils.ts` | `cn()` — clsx + tailwind-merge |

### Backend schema

| Table / bucket | Purpose |
| :-- | :-- |
| `certificates` | Certificate title, provider, file path, sort order |
| `contact_messages` | Contact form submissions |
| `site_settings` | Editable location and CV link |
| `user_roles` | Role-based access control |
| `certificates` (storage) | Private bucket served via short-lived signed URLs |

All tables are protected with Row Level Security; public read where appropriate, writes restricted to the admin account.
