# Footer redesign

## Scope
- Replace the current footer with a full-width deep navy design and thin light-gray separators.
- Add a large diagonal white-to-navy transition at the top without changing page content.
- Add a centered “Let’s Work Together” call-to-action with a white pill button linking to Contact.
- Organize the lower footer into four responsive columns: Navigation, Portfolio, Contact, and Social.
- Preserve the existing phone, email, LinkedIn, GitHub, copyright, and “Built with care” content.
- Add restrained link/icon movement and clear keyboard focus states.

## Technical details
- Define the requested navy, white, muted, and separator colors as semantic footer tokens in the global styles.
- Use the existing shared button component for the call-to-action.
- Keep the footer stacked on mobile, two columns on tablet, and four columns on desktop.
- Verify the result in the live preview at desktop and mobile sizes and confirm the project still builds cleanly.
